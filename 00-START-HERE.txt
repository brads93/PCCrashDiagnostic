PC CRASH DIAGNOSTIC 3.2 - START HERE

This is the ShareReadOnly portable build. Nothing is installed. It contains
one app, PCCrashDiagnostic.exe, and does not ask for administrator access or
change Windows crash settings.

ONLY RUN AN APPROVED, SIGNED RELEASE

Do not run a developer candidate sent as a loose Discord attachment. A shared
release should identify its publisher in the Digital Signatures tab and should
not show Unknown publisher. If Windows asks for administrator permission, click
No: the ShareReadOnly build never needs UAC.

1. EXTRACT THE ZIP

Right-click the runtime ZIP, choose Extract All, and open the extracted folder.
Do not run the app from inside the ZIP preview.

2. CHECK AND SCAN IT

Right-click PCCrashDiagnostic.exe, choose Properties, and check the Digital
Signatures tab. An approved open-source release is expected to show a valid
SignPath Foundation publisher signature, matching the official release page.
Then right-click the extracted folder or EXE and choose Scan with
Microsoft Defender (Show more options may be required).

Do not disable Defender, SmartScreen, UAC, anti-cheat, or another security
feature for this app. You do not need to compare a hash manually.

3. RUN THE APP

Double-click PCCrashDiagnostic.exe. Choose the closest match:

- Windows restarted or showed a blue screen
- An app or game closed or froze
- Monitor an app for the next problem
- Open a previous report

The app reads Windows diagnostic evidence available to your account. It does
not control the selected program, send mouse or keyboard input, inject code,
read process memory, or interact with anti-cheat.

4. REVIEW THE RESULT

Read Evidence collected, Crash capture readiness, and Source coverage. A named
driver or hardware category is not proof that part caused the crash. The app
may correctly report that no cause was identified in the Windows records it
could read.

5. SHARE THE SAFE SUMMARY FIRST

Choose Review safe summary. Read the exact text, then copy or save it if you are
comfortable sharing it. This is the best first item to send to a Discord helper.

The advanced technical report contains more machine detail. Export it only
after reading the warning, and inspect the ZIP before sharing. The standard
technical report does not contain crash-dump bytes or raw debugger logs.

Reports stay on this PC until you export them. Local history can be moved to the
Recycle Bin from the app; that is recoverable deletion, not secure erasure.
