PC CRASH DIAGNOSTIC - START HERE

This is a portable app. Nothing is installed.

This controlled beta is not digitally signed. The settings-changing build is
for developer and controlled VM testing until both executables are signed and
the final release passes its Windows VM security checks.

1. EXTRACT THE ZIP

Right-click the runtime ZIP, choose Extract All, and open the extracted folder.
Do not run the app from inside the ZIP preview.

2. SCAN THE EXTRACTED FOLDER

Right-click the folder or PCCrashDiagnostic.exe, choose Show more options if
needed, then choose Scan with Microsoft Defender. Do not disable Defender,
SmartScreen, UAC, anti-cheat, or another security feature for this app.

3. RUN THE APP

Double-click PCCrashDiagnostic.exe. The main app uses your normal Windows
account and does not ask for administrator access at startup.

4. CHOOSE WHAT HAPPENED

- For a blue screen or restart, choose Windows restarted or showed a blue
  screen, select the incident, then analyze it.
- For an app or game crash, choose An app or game closed or froze and select
  the app.
- To watch the next session, choose Monitor an app for the next problem.

The app does not control the selected program or send mouse or keyboard input.

5. OPTIONAL: PREPARE FOR THE NEXT CRASH

Prepare this PC for the next crash first shows every proposed setting. Continue
only if those changes are acceptable. Windows then asks to run exactly
PCCrashDiagnostic.ElevatedHelper.exe. The helper makes the shown changes,
checks them, saves the previous values, and exits. Windows is never restarted
automatically.

After a restart, the Start screen keeps an option to restore the earlier
settings. Restore asks for UAC again and will not overwrite settings changed by
another program or policy.

Distributable beta.2 packages do not enable new Advanced app dumps. That
experimental WER path remains source-only for disposable-VM research because
Windows keys it by executable name. If this app finds a saved receipt from an
earlier developer build, it still offers to restore the earlier settings.

Close Battlefield 6 before any helper, dump, or debugger operation.

6. REVIEW AND EXPORT

When the report is ready, choose Review and export. The normal report does not
contain crash-dump bytes or raw debugger output. A dump ZIP is always a
separate, explicit action with its own privacy warning.

The app checks its helper automatically. There is no manual hash step in the
app. Developer release folders still contain SHA256SUMS.txt and source code for
optional independent verification; a hash confirms file integrity, not who
published the file.
